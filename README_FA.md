# ربات فایل روبیکا

این پروژه برای اجرای آنلاین ربات فایل روبیکا آماده شده است.

## قابلیت‌ها
- ثبت فایل با فرستادن فایل به ربات توسط مدیر
- ساخت کد اختصاصی برای هر فایل
- لینک شروع اختصاصی
- جوین اجباری یک یا چند کانال
- بررسی عضویت
- ارسال فایل با `forwardMessage` بدون نگهداری فایل روی سرور
- آمار کاربران، فایل‌ها و دریافت‌ها
- SQLite برای ذخیره اطلاعات

## نکته مهم درباره فایل
فایل اصلی در پیام روبیکا باقی می‌ماند و ربات هنگام درخواست آن را فوروارد می‌کند؛ بنابراین این نسخه فضای دیسک سرور را برای فایل‌ها مصرف نمی‌کند.

## متغیرها
`RUBIKA_TOKEN` توکن ربات است.
`ADMIN_ID` شناسه عددی/رشته‌ای مدیر است.
`BOT_USERNAME` نام کاربری ربات بدون @ است.
`CHANNELS` هر کانال را در یک خط با این قالب قرار بده:

@username|channel_guid|https://rubika.ir/username|نام کانال

برای چند کانال، هر کدام را در خط جدا قرار بده.

## استقرار
در Render یک Web Service بساز و Repository گیت‌هاب را وصل کن.
Build:
pip install -r requirements.txt

Start:
gunicorn app:app

Environment Variables را در Render وارد کن.

## هشدار امنیتی
توکن ربات را داخل GitHub یا فایل‌های عمومی قرار نده.
